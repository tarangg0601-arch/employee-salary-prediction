# Employee Salary Prediction

This project predicts employee salary using machine learning.

[Open in Google Colab](https://colab.research.google.com/github/tarangg0601-arch/employee-salary-prediction/blob/main/Employee_Salary_Prediction.ipynb)

## Dataset

The dataset contains:

- Age
- Gender
- Education Level
- Job Title
- Years of Experience
- Salary

## Model

Linear Regression

## Project Flow

```text
Dataset
   ↓
Data Cleaning
   ↓
Data Visualization
   ↓
Feature Encoding
   ↓
Train-Test Split
   ↓
Linear Regression
   ↓
Salary Prediction
   ↓
Model Evaluation
```

## Results

- MAE: 15741.89
- RMSE: 21483.39
- R² Score: 0.8316
